# Afterglow

A responsive landing page for **Afterglow**, a fictional night-market festival concept set in Skopje.

This project keeps the original design intact and separates the page into simple, editable files:

- **index.html** — page content and structure
- **styles.css** — layout, typography, colors, responsive styling, and motion
- **script.js** — mobile navigation and the interactive three-night schedule
- **assets/** — original AI-created illustrative festival scenes

## Preview locally

Open index.html in a browser. The page has no build step or package dependencies. The web fonts load from Google Fonts; system-font fallbacks are included.

## Publish with GitHub Pages

1. Create a GitHub repository and add these project files.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select **main** and the root folder, then save.
4. After GitHub Pages finishes publishing, use the provided site URL.

The festival, dates, schedule, and venue details are fictional sample content. The photo-style scenes are AI-generated illustrations, not documentation of a real event.
